# via_kairos# 🤖 Бот «Кайрос» — проверка подписки + выдача подарка

Бот проверяет, подписан ли пользователь на твой Telegram-канал, и если да — выдаёт файл-подарок (гайд). Если не подписан — просит подписаться и даёт кнопку «Проверить».

---

## 1. Что нужно сделать заранее (5 минут)

### 1.1 Создай бота через @BotFather
1. В Telegram открой `@BotFather` → `/newbot`
2. Придумай имя: `Кайрос | Подарки`
3. Придумай username (обязан заканчиваться на `bot`): например `kairos_gift_bot`
4. BotFather пришлёт **токен** вида `123456789:AA...` — сохрани его.

### 1.2 Создай канал (если ещё нет)
1. В Telegram: «Создать канал» → назови, например, `Кайрос | Клуб`
2. Скопируй username канала (например `@kairos_club`) — это твой `CHANNEL_ID`.

### 1.3 Добавь бота в канал АДМИНОМ (обязательно)
1. Открой канал → «Администраторы» → «Добавить» → найди своего бота.
2. Права: «Добавлять подписчиков» можно отключить, остальное неважно — боту нужен доступ к списку участников.

### 1.4 Положи файл-подарок рядом с ботом
- Файл должен называться так же, как в настройке `GIFT_PATH` (по умолчанию `guide.pdf`).
- Лучше PDF (удобнее на телефоне). Твой HTML-гайд пересохрани в PDF (в браузере: «Печать → Сохранить как PDF») и переименуй в `guide.pdf`.

## 2. Запуск

### Вариант А — локально (для проверки)
```bash
cd bot
pip install -r requirements.txt
BOT_TOKEN="ТВОЙ_ТОКЕН" CHANNEL_ID="@kairos_club" python3 bot.py
```
Напиши боту `/start` — проверь, что кнопка и выдача файла работают.

### Вариант Б — Railway (простой хостинг, есть бесплатный стартовый кредит)
1. Зарегистрируйся на railway.app, создай New Project → Deploy from GitHub.
2. Залей папку `bot/` на GitHub (файлы: `bot.py`, `requirements.txt`, `guide.pdf` + добавь `Procfile` со строкой `worker: python bot.py`).
3. В настройках проекта задай переменные окружения (Variables):
   - `BOT_TOKEN` = твой токен
   - `CHANNEL_ID` = `@kairos_club`
   - `GIFT_PATH` = `guide.pdf`
4. Railway сам установит зависимости из `requirements.txt` и запустит бота.

### Вариант В — VPS (любой, ~150–300 ₽/мес)
```bash
# на сервере:
apt update && apt install -y python3 python3-pip
mkdir ~/bot && cd ~/bot
# залей bot.py, requirements.txt, guide.pdf
pip install -r requirements.txt
# запусти в фоне, чтобы работал после закрытия терминала:
nohup env BOT_TOKEN="ТОКЕН" CHANNEL_ID="@kairos_club" python3 bot.py > bot.log 2>&1 &
```

## 3. Как проверить, что всё работает
1. Отпишись от канала → напиши боту `/start` → должна прийти просьба подписаться + кнопка.
2. Нажми кнопку, НЕ подписавшись → бот должен ответить «Подписка не найдена».
3. Подпишись → нажми кнопку → бот пришлёт `guide.pdf` + приглашение в клуб.
